## 1. 핵심 인사이트

### 인사이트 1. 진짜 문제는 "여행"이 아니라 "혼자"다

혼밥 부담(5명), 외로움·동행 부재(4명), 사진 찍어줄 사람 없음(4명), 안전 걱정(6명)은 서로 다른 페인처럼 보이지만 모두 **"혼자여서 발생하는 제약"**이라는 하나의 뿌리에서 나온다. 기존 여행 앱(트리플, 마이리얼트립 등)은 "여행 정보·예약" 문제를 풀 뿐, "혼자"라는 조건이 만드는 문제는 다루지 않는다. → **경쟁 앱과 같은 링에서 싸울 필요가 없다.**

### 인사이트 2. 안전은 가장 강도 높은 페인이자, 여행 빈도를 늘리는 지렛대다

- 안전 관련 페인의 점수는 대부분 5점(최고 강도)이며, 긴급 SOS는 필수 기능 9회 언급으로 최다 요구 기능이다.
- 결정적 단서: R001 *"안전만 보장되면 혼자 여행을 더 자주 다닐 것 같다"*, R010 *"가족에게 위치를 공유할 수 있으면 안심하고 떠난다"*, R023 *"혼자 다녀도 편하고 안전하면 시간 내서 떠난다"*.
- 즉 안전은 불편을 줄이는 기능이 아니라 **억눌린 수요를 풀어 여행 자체를 늘리는 기능**이다. 시장 크기를 키우는 레버라는 점에서 전략적 가치가 가장 크다.

### 인사이트 3. 지불 의사가 높은 그룹이 가입 의향도 가장 높다 — 수익화 경로가 뚜렷하다

가격 선호별 평균 가입 의향을 계산하면:

| 가격 선호 | 인원 | 평균 가입 의향 | 특징 |
|---|---|---|---|
| 월 구독 | 7명 | **약 4.6 / 5** | 디지털 노마드·40대 직장인·주부, 연 2~6회 여행, 예산 110만~160만원 |
| 건당 결제 | 14명 | 약 3.9 / 5 | 20~30대 직장인 여성 중심, 최다 그룹 |
| 무료 | 9명 | 약 3.7 / 5 | 대학생·취준생 중심, 예산 40만~60만원 |

"돈을 낼 사람일수록 더 절실하다"는 구조여서, **무료 사용자 확보 → 전환** 같은 우회로 없이 처음부터 지불 고객을 직접 겨냥할 수 있다.

### 인사이트 4. 구독 그룹은 "시간"을 사고, 건당 그룹은 "안심"을 산다

- 월 구독 그룹(노마드·40대 직장인)의 페인은 정보 흩어짐, 일정 짜기 번거로움 — *"알아서 다 해주면 비용을 지불한다"*(R030), *"정보 모으는 시간을 줄여주면 바로 결제한다"*(R004). **시간 절약에 반복 과금**이 성립한다.
- 건당 결제 그룹(20~30대 여성)의 페인은 안전·혼밥 — 여행이라는 이벤트 단위로 발생하므로 **여행 1건 단위 과금**이 자연스럽다.
- 결론: 단일 가격 모델은 두 그룹 중 하나를 버리는 선택이다. 과금 축을 "안심 패스(건당)"와 "플래닝 구독(월)"로 분리하는 하이브리드가 데이터에 부합한다.

### 인사이트 5. "연결"은 원하지만 "커뮤니티"는 원하지 않는다

그룹 패키지와 커뮤니티 피드는 "안 쓸 기능"으로 가장 자주 지목된 반면, 동행 매칭은 6회 요구됐다. 혼자 여행자는 **목적이 분명하고(액티비티·식사 동행), 안전이 인증된, 느슨한 1:1 연결**만 원한다. 커뮤니티·피드형 기능은 만들지 않는 것이 오히려 포지셔닝을 선명하게 한다.

### 인사이트 6. 전용 도구의 공백 — 현재 대체재는 모두 범용 채널이다

30명 전원이 인스타그램, 유튜브, 네이버 블로그, 구글맵 등 **1인 여행 전용이 아닌 범용 채널**을 조합해 쓰고 있다. 페인(정보 흩어짐 3명, 신뢰도 낮음 2명, 일정 짜기 번거로움 4명)은 이 조합의 부산물이다. 직접 경쟁자가 없는 공백 시장이라는 뜻이지만, 동시에 "습관이 된 무료 대체재"를 이겨야 한다는 뜻이기도 하다.

## 2. 타깃 세그먼트 우선순위

| 우선순위 | 세그먼트 | 선정 근거 | 역할 |
|---|---|---|---|
| **1차 (Beachhead)** | 20~30대 여성 직장인·주부 | 페인 강도 최고(안전 5점), 가입 의향 5점 응답 집중, 건당 지불 의사 | 초기 핵심 고객·입소문 원천 |
| **2차** | 디지털 노마드·크리에이터·40대 직장인 | 여행 빈도 높음(연 4~6회), 월 구독 의사, 평균 가입 의향 최고 | 반복 매출(구독) 기반 |
| **후순위** | 대학생·취준생 | 무료 선호, 가입 의향 상대적 낮음 | 수익화 제외, 바이럴 채널로만 활용 |
| **보류** | 50대 시니어 | 니즈는 있으나 "복잡하면 포기" — 별도 UX 투자 필요 | 제품 성숙 후 재검토 |

## 3. 핵심 전략 (가설)

### 3.1 가치 제안

> **"혼자여서 못 하던 여행을, 혼자서도 안심하고 하게 만든다."**

- 1차 고객에게: 긴급 SOS·실시간 위치 공유·안전 검증 숙소로 "혼자 여행의 안전망"을 제공한다.
- 2차 고객에게: 검증된 정보 기반 자동 일정 추천으로 "여행 준비 시간"을 돌려준다.

### 3.2 포지셔닝

- "여행 예약 앱"이 아니라 **"1인 여행자의 안전·동반 인프라"**로 포지셔닝한다. 예약·정보는 수단이고, 파는 것은 안심과 시간이다.
- 안티 포지셔닝: 그룹 패키지·커뮤니티 피드는 의도적으로 만들지 않는다 (인사이트 5).

### 3.3 MVP 기능 우선순위

| 순위 | 기능 | 근거 (요구 횟수 / 대상) |
|---|---|---|
| P0 | 긴급 SOS + 실시간 위치 공유(가족 공유) | 9회 / 1차 타깃의 최강 페인 |
| P0 | 안전 검증 1인 숙소 큐레이션 | 숙소 관련 9회(안전 숙소+1인 숙소) / 1·2차 공통 |
| P1 | 자동 일정 추천 (검증된 정보 기반) | 7회 / 2차 타깃 구독 전환 핵심 |
| P1 | 1인 식당(혼밥) 추천 | 5회 / 1차 타깃 반복 사용 유도 |
| P2 | 동행 매칭 (신원 인증 전제) | 6회 요구되나 신뢰·안전 설계 난도가 높아 후속 단계로 |
| 제외 | 그룹 패키지, 커뮤니티 피드, 마일리지·가계부 | "안 쓸 기능" 최다 지목 |

### 3.4 수익 모델 (가설)

- **안심 패스 (건당)**: 여행 1건 단위로 SOS·위치 공유·안전 숙소 큐레이션 묶음 판매 → 1차 타깃 (건당 선호 14명).
- **플래닝 구독 (월)**: 자동 일정·검증 정보·장기 숙소 큐레이션 → 2차 타깃 (구독 선호 7명, 가입 의향 최고).
- 무료 티어는 최소화하고, 대학생·취준생 대상 할인은 바이럴 목적일 때만 검토한다.

### 3.5 하지 않을 것 (Non-goals)

1. 대규모 커뮤니티·피드 기능 — 타깃이 명시적으로 기피.
2. 항공권 비교·마일리지·가계부 등 범용 여행 유틸리티 — "안 쓸 기능" 다수 지목, 기존 앱과의 소모전.
3. 초기 단계의 시니어 전용 UX — 니즈는 확인됐으나 별도 투자 규모가 커서 보류.

## 4. 검증 계획

| 가설 | 검증 방법 | 성공 기준 (제안) |
|---|---|---|
| 안전 기능이 가입·재사용을 견인한다 | 가입 의향 5점 + 연락 가능 응답자 우선 심층 인터뷰 (22명 풀) | 안전 페인 응답자의 유료 전환 의사 확인 |
| 건당 + 구독 하이브리드가 성립한다 | 가격 제시형 랜딩페이지 A/B 테스트 (안심 패스 vs 구독) | 세그먼트별 결제 의사 클릭률 유의미 차이 |
| 자동 일정이 구독을 정당화한다 | 노마드·40대 대상 컨시어지 MVP(수동 일정 대행)로 지불 의사 실측 | 월 구독 가격에 실제 결제 발생 |
| 동행 매칭의 안전 인증이 구현 가능하다 | 본인 인증·후기 체계 리서치 + 소규모 파일럿 | 파일럿 참여자의 신뢰도 평가 |

### 열린 질문 (요약본에서 이어짐)

- SOS·위치 공유의 실시간성·정확도를 어느 수준까지 보장할 수 있는가? (신뢰가 곧 제품)
- 건당 결제의 과금 단위는 무엇인가? — 여행 1건 단위 "안심 패스"를 기본 가설로 검증
- 동행 매칭의 신원 인증 방식 (본인 인증, 후기, 신원 확인 등)

## 5. 리스크

| 리스크 | 성격 | 대응 |
|---|---|---|
| SOS·위치 공유의 기술적 신뢰성 미달 → 브랜드 치명상 | 제품 | 초기에는 보수적 SLA로 시작, 기능 범위보다 신뢰성 우선 |
| 무료 범용 채널(인스타·유튜브) 습관을 못 이김 | 시장 | 범용 채널이 못 푸는 "안전"으로 차별화, 정보 기능 단독 승부 회피 |
| 동행 매칭 안전 사고 발생 시 서비스 전체 신뢰 붕괴 | 운영 | P2로 후순위화, 인증 체계 검증 전 출시 금지 |
| 구독·건당 이원화로 가격 커뮤니케이션 복잡 | 사업 | 세그먼트별 진입 경로 분리 (마케팅 메시지도 이원화) |
