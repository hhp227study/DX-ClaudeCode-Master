# Quickstart 검증 가이드: 사이드바 접기/펼치기

**Date**: 2026-07-16 | **Spec**: [spec.md](./spec.md) | **Contract**: [contracts/ui-contract.md](./contracts/ui-contract.md)

## 사전 조건

- Node.js 및 의존성 설치: `npm install`
- Supabase 환경변수: `.env.local` 존재 (로그인 필요 — 앱은 미로그인 시 `/login`으로 리다이렉트)

## 실행

```bash
npm run dev   # 기본 3000 포트 (충돌 시: npx next dev -p 3100)
```

브라우저에서 `http://localhost:3000` 접속 후 로그인.

## 검증 시나리오

### V1. 기본 토글 (US1 / FR-001~003)

1. 홈 화면에서 사이드바 상단의 토글 버튼(«)을 클릭
2. **기대**: 사이드바가 아이콘 레일(약 52px)로 접히고 본문이 넓어진다. 글 목록·텍스트 레이블이 사라진다. 전환은 0.5초 이내
3. 레일의 토글 버튼(»)을 다시 클릭
4. **기대**: 사이드바가 원래 모습(248px, 브랜드·검색·새 글·글 목록·프로필)으로 복원된다

### V2. 접힘 상태 기능 접근 (US2 / FR-004~005)

1. 사이드바를 접는다
2. **기대**: 레일에 토글·검색·새 글 아이콘, 하단에 프로필 아바타만 보인다 (글 목록 없음)
3. 검색 아이콘 클릭 → **기대**: 검색 모달이 열린다 (닫은 뒤에도 레일 유지)
4. 새 글 아이콘 클릭 → **기대**: 새 글이 생성되고 해당 글 화면으로 이동, 사이드바는 접힌 채 유지
5. 프로필 아바타 클릭 → **기대**: 프로필 화면으로 이동, 사이드바는 접힌 채 유지

### V3. 상태 유지·복원 (US3 / FR-006~007)

1. 사이드바를 접은 상태에서 홈 → 글 상세 → 프로필로 이동
2. **기대**: 모든 화면에서 접힌 상태 유지
3. 브라우저 새로고침 (F5)
4. **기대**: 접힌 상태로 복원 (DevTools → Application → Local Storage에 `mini-notion-sidebar: "collapsed"` 확인)
5. 사이드바를 펼치고 새로고침 → **기대**: 펼쳐진 상태로 복원
6. Local Storage에서 `mini-notion-sidebar` 삭제 후 새로고침 → **기대**: 기본값인 펼침 상태

### V4. 엣지 케이스

1. 접힌 상태에서 `Cmd/Ctrl+K` → **기대**: 검색 모달 정상 동작
2. 토글 버튼 빠르게 5회 연속 클릭 → **기대**: 최종 클릭 기준 상태(홀수 회=반전)로 정착, 레이아웃 깨짐 없음
3. 전환 애니메이션 중 다른 글 클릭(펼침 상태에서) → **기대**: 이동 후에도 레이아웃 정상

### V5. 접근성 (FR-008~009)

1. Tab 키로 토글 버튼에 포커스 → Enter → **기대**: 접힘/펼침 동작
2. DevTools에서 토글 버튼 검사 → **기대**: `aria-expanded`가 상태에 맞게 `true`/`false`, `aria-label`이 "사이드바 접기"/"사이드바 펼치기"로 전환
3. 접힌 레일의 검색·새 글·프로필 아이콘에 마우스 호버 → **기대**: 이름 툴팁(title) 표시
