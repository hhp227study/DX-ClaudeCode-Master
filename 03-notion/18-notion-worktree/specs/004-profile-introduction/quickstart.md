# Quickstart: 자기소개 기능 검증 가이드

**Date**: 2026-07-16 | **Plan**: [plan.md](./plan.md) | **Contract**: [contracts/profile-data-contract.md](./contracts/profile-data-contract.md)

이 프로젝트에는 자동화 테스트 프레임워크가 없으므로, 빌드 검증 + 아래 수동 시나리오가 완료 기준(Definition of Done)이다.

## 사전 조건

- `.env.local`에 `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` 설정 (기존 파일 그대로)
- Google 로그인 가능한 계정 (기존 OAuth 설정 사용)
- 의존성 설치: `npm install`

## 실행

```bash
npm run dev
# http://localhost:3000 접속 → Google 로그인 → 우측 상단/사이드바에서 마이 페이지 진입
```

## 검증 시나리오

### S1. 등록 및 조회 (US1 / P1)

1. 자기소개가 비어 있는 계정으로 마이 페이지 진입
2. ✅ 자기소개 입력란이 별명 아래 표시되고, 비어 있으면 placeholder 안내 문구가 보인다
3. 여러 줄 자기소개 입력(줄바꿈 포함) → [저장]
4. ✅ 2초 이내 "저장되었습니다 ✓" 표시
5. 페이지 새로고침 → ✅ 줄바꿈 포함 동일 내용이 입력란에 표시
6. 로그아웃 → 재로그인 → ✅ 동일 내용 유지 (FR-004)

### S2. 수정 (US2 / P2)

1. S1 완료 상태에서 내용 수정 → [저장]
2. ✅ 성공 피드백 후 새로고침 시 수정된 내용 표시
3. (실패 경로) 개발자도구 Network를 Offline으로 → 수정 후 [저장]
4. ✅ 오류 메시지 표시 + 작성 중이던 내용 유지 (FR-008)

### S3. 비우기 (US3 / P3)

1. 내용 전체 삭제(또는 공백·줄바꿈만 입력) → [저장]
2. ✅ 저장 성공, 새로고침 후 빈 입력란 + placeholder 표시
3. ✅ (선택) Supabase 대시보드에서 `profile.introduction`이 `null`인지 확인

### S4. 길이 제한 (FR-006)

1. 500자를 넘는 텍스트 붙여넣기 시도
2. ✅ 입력이 500자에서 잘리거나, 저장 시 초과 안내와 함께 저장 차단

### S5. 회귀 확인 (FR-010 / SC-004)

1. ✅ 별명 변경 → 저장 → 새로고침 후 유지 (기존 동작)
2. ✅ 별명 저장과 자기소개 저장을 연달아 수행해도 서로 값을 훼손하지 않음
3. ✅ 프로필 이미지 변경/제거, 로그아웃 정상 동작
