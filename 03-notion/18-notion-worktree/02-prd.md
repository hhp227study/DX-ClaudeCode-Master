# PRD: 미니 노션 (Mini Notion)

개인 업무 관리를 위한 나만의 웹 서비스

---

## 1. 요약 (Summary)

이 문서는 개인 업무 관리용 웹 서비스 **"미니 노션"** 의 제품 요구사항을 정의합니다. 사용자는 구글 계정으로 로그인한 뒤, 노션처럼 글(페이지)을 만들고 편집하며 자신의 업무를 관리할 수 있습니다. 유료 구독 없이 무료로 쓸 수 있고, 필요할 때마다 나에게 맞는 기능을 직접 추가할 수 있는 개인 맞춤형 도구를 만드는 것이 목표입니다.

## 3. 배경 (Background)

**무엇에 관한 프로젝트인가?**
노션(Notion) 같은 업무 관리 도구는 편리하지만, 개인이 쓰기에는 기능이 너무 많고 일부 기능은 유료입니다. 이 프로젝트는 개인에게 꼭 필요한 핵심 기능만 담은 가벼운 노션을 직접 만드는 것입니다.

**왜 지금인가?**
- 상용 도구는 무료 플랜에 제한이 있고, 원하는 기능을 마음대로 추가할 수 없습니다.
- 직접 만들면 비용이 들지 않고, 내 업무 방식에 딱 맞게 기능을 확장할 수 있습니다.
- 구글 로그인, 클라우드 배포 등 개인이 쓸 수 있는 무료 인프라가 충분히 성숙해져, 혼자서도 빠르게 만들 수 있는 환경이 되었습니다.

## 4. 목표 (Objective)

**목표가 무엇이고, 왜 중요한가?**
매일 쓸 수 있는 개인 업무 관리 도구를 직접 만들어 운영합니다. 이를 통해:
- **비용 절감**: 유료 구독 없이 무료로 사용합니다.
- **완전한 소유권**: 내 데이터와 기능을 내가 통제합니다.
- **맞춤 확장**: 개인용이므로 남 눈치 볼 것 없이, 나에게 최적화된 기능을 계속 추가합니다.

**핵심 결과 (Key Results)**

| # | Key Result | 측정 방법 |
|---|-----------|----------|
| KR1 | 첫 버전 출시 후, 구글 로그인 → 글 작성 → 글 삭제까지 전체 흐름이 오류 없이 동작 | 핵심 시나리오 수동 테스트 통과 |
| KR2 | 기존에 다른 도구로 하던 개인 업무 기록을 100% 미니 노션으로 이전 | 사용 도구 전환 완료 여부 |
| KR3 | 출시 후 주 3회 이상 실제 업무 관리에 사용 | 본인 사용 빈도 |

## 5. 시장 세그먼트 (Market Segments)

**누구를 위해 만드는가?**
"개인 업무를 스스로 관리하고 싶은 사용자" — 1차적으로는 개발자 본인입니다. 시장은 인구 통계가 아니라 **해결하려는 문제**로 정의합니다:

- 할 일과 업무 메모를 한곳에 기록하고 싶은 사람
- 기존 도구(노션 등)가 너무 무겁거나, 유료 기능 제한이 불편한 사람
- 자신의 업무 방식에 맞게 도구를 커스터마이징하고 싶은 사람

**제약 조건**
- 1인 개발이므로 개발 리소스가 제한적입니다. → 핵심 기능에 집중합니다.
- 무료 운영이 전제이므로, 인프라는 무료 티어 범위 안에서 선택합니다.
- 다중 사용자 협업은 목표가 아닙니다. (개인용)

## 6. 가치 제안 (Value Propositions)

**어떤 고객의 일(Job)을 해결하는가?**
"내 업무를 기록하고, 다시 찾아보고, 정리한다"라는 개인 지식 관리 작업을 해결합니다.

| 구분 | 내용 |
|------|------|
| **얻는 것 (Gains)** | 무료 사용, 빠르고 가벼운 화면, 내 방식대로 확장 가능한 도구 |
| **피하는 고통 (Pains)** | 유료 구독 비용, 쓰지 않는 기능으로 인한 복잡함, 기능 요청이 반영되지 않는 답답함 |
| **경쟁 대비 강점** | 상용 도구는 "모두를 위한 기능"을 제공하지만, 미니 노션은 "나를 위한 기능"만 제공 — 단순함과 맞춤성에서 우위 |

**가치 곡선 관점**: 기능 수, 협업, 템플릿 다양성은 과감히 낮추고(제거), 단순함·속도·개인 맞춤성은 상용 도구보다 높입니다.

## 7. 솔루션 (Solution)

### 7.1 UX / 화면 흐름

```
[로그인 페이지] --구글 로그인--> [업무 페이지 (글 목록)]
                                      |
                                      |-- "/page" 입력 --> 새 글 생성
                                      |-- 글 클릭 --> [글 상세 페이지]
                                      |                  |-- 제목/내용 편집
                                      |                  |-- 글 삭제 --> 목록으로
                                      |
                                      '-- 프로필 클릭 --> [마이 페이지]
                                                            |-- 별명 변경
                                                            '-- 프로필 이미지 변경
```

### 7.2 핵심 기능 (Key Features)

**① 로그인 페이지**
- **구글 로그인**: 별도 회원가입 없이 구글 계정 하나로 로그인합니다. 비밀번호를 따로 관리할 필요가 없습니다.

**② 마이 페이지**
- **별명 변경**: 서비스 안에서 표시될 이름을 자유롭게 바꿀 수 있습니다.
- **프로필 이미지**: 프로필 사진을 등록하고 변경할 수 있습니다.

**③ 업무 페이지 (핵심 화면)**
- **`/page` 명령으로 새 글 생성**: 노션처럼 `/page`를 입력하면 새 글이 만들어집니다.
- **글 목록 → 상세 이동**: 목록에서 글을 클릭하면 해당 글의 상세 화면으로 이동합니다.
- **제목·내용 편집**: 글 상세에서 제목과 내용을 자유롭게 입력하고 수정할 수 있습니다.
- **글 삭제**: 더 이상 필요 없는 글을 삭제할 수 있습니다.

### 7.3 기술 (Technology)

- **인증**: 구글 OAuth 소셜 로그인
- **인프라**: 무료 티어로 운영 가능한 스택 선택 (예: Vercel 배포 + Supabase 인증/DB — 기존 프로젝트에서 검증된 조합)
- 세부 기술 스택은 구현 단계에서 확정합니다.

### 7.4 가정 (Assumptions)

검증되지 않았지만 참이라고 믿는 것들입니다. 개발 중 확인이 필요합니다:

1. 구글 로그인 하나면 충분하다 — 다른 소셜 로그인은 필요 없다.
2. 무료 티어 인프라만으로 개인 사용량(글 수백 개 수준)을 감당할 수 있다.
3. `/page` 명령 방식이 버튼 클릭보다 사용 경험이 좋다.
4. 텍스트 기반 제목+내용 구조만으로 초기 업무 관리가 가능하다. (체크리스트, 마감일 등은 추후 확장)

## 8. 릴리스 (Release)

**예상 기간**: 1인 개발 기준, 첫 버전(V1)은 수 주 이내 목표. 정확한 날짜보다 범위 관리에 집중합니다.

**V1 (첫 버전) — 핵심 흐름 완성**
- 구글 로그인
- 업무 페이지: `/page`로 글 생성, 목록, 상세 이동
- 글 상세: 제목·내용 편집, 삭제
- 마이 페이지: 별명 변경, 프로필 이미지

**V2 이후 (확장 후보) — 사용하면서 필요해지는 것부터**
- 글 검색, 태그/분류
- 체크리스트·마감일 등 업무 특화 필드
- 마크다운 지원, 블록 에디터 고도화
- 그 외 "나에게 최적화된" 기능을 사용 경험에 따라 추가

> 원칙: V1은 "매일 쓸 수 있는 최소한의 도구"를 빠르게 만들고, 확장은 실제 사용에서 느낀 불편에서 출발합니다.
