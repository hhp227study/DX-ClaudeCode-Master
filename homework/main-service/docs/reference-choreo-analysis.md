# 레퍼런스 댄스 영상 분석 → 채보 안무 규칙 (2026-07-08)

`reference/` 폴더의 셀카 댄스 영상들을 MediaPipe Pose(Landmarker Lite)로 전 프레임 분석해,
"자연스러운 셀카 댄스 동작"을 채보 생성 규칙으로 번역했다. 결과는 `web/scripts/gen-chart.mjs`의
안무(choreography) 상수에 반영되어 있다.

**표준 영상**: 유저가 `reference/best.mp4`를 "채보가 나타나야 하는 모습의 베스트 표준"으로
지정했다. 5개 영상 풀링은 공통 패턴(앵커존·교대·모티프)의 근거로, best.mp4는 y 높이와
모티프 가중치의 기준으로 쓴다.

## 분석 방법

- 영상: 세로 셀카 댄스 5개 (11~24초, 480~720p) — 클로즈업 3개, 상반신~전신 2개
- 파이프라인: OpenCV 프레임 디코드 → PoseLandmarker(VIDEO 모드) → 손목·어깨·코 궤적 추출
- 좌표는 어깨 중심·어깨 너비로 정규화(body unit)해 프레이밍 차이를 제거
- "드웰(dwell)" = 손목 속도가 낮게 유지되는 0.12초 이상 구간 = 동작이 비트에 걸리는 지점
  (노트가 놓여야 할 위치·간격의 근거)

## 도출된 안무 규칙 (gen-chart.mjs 구현)

1. **좌우 교대 그루브** — 노트는 좌(x≈0.28)/우(x≈0.72) 앵커존을 교대로 오간다.
   양손이 번갈아 움직이는 자연스러운 댄스가 되고, 동시에 화면에 떠 있는 두 노트가
   겹치지 않는다(가독성).
2. **4노트 프레이즈 모티프 (가중치 선택)** — 무작위 개별 배치 대신 4노트 단위 모티프를
   굴린다: `sway`(좌우 스웨이) / `arc`(팔 스윕: 바깥→안→안→바깥) / `build`(고조,
   끝은 액센트) / `heart`(좌·우·중앙·중앙 모아주기 — best.mp4 시그니처).
   가중치: easy sway45/arc30/heart25, normal sway30/arc20/build20/heart30.
3. **어깨~가슴 높이 우선 (best.mp4 표준)** — 기본 y는 0.50~0.66의 사이드별 랜덤 워크
   (경계 반사), 프레이즈 마지막 노트만 0.45~0.53 액센트. (확정 밴드 0.45~0.73 안에서만.
   인접 노트 겹침 분리 시에만 밴드 전체를 쓴다)
4. **스텝 상한** — 같은 쪽 연속 노트의 이동 폭 제한(x 지터 ±0.07, y 스텝 ≤0.10).
   손이 관성적으로 흐르는 경로 위에 노트가 놓인다.
5. **함정(decoy)은 흐름의 반대편** — 직전에 잡은 자리 근처(잡은 손이 물러나는 자리)에
   y를 ±0.15 비켜 배치 — 주로 동선 아래 허리 높이(~0.73까지 허용)로 내려간다.
   다음 캐치와 겹치면 치환을 포기한다(억울한 함정 방지). 프레이즈 액센트 자리에는 두지 않는다.
6. **포즈 노트 유지** — hands_up/heart는 섹션 경계(고조 지점)에 그대로. 영상에서도
   손 올리기·하트는 프레이즈 클라이맥스에서만 짧게 나온다.

## 프레이밍 분류 — 클로즈업 셀카 vs 풀바디/트라이포드 (2026-07-12)

카라멜단센 영상들은 기존 레퍼런스(가까운 셀카)와 달리 전부 먼 풀바디 촬영이다.
MediaPipe 랜드마크 두 가지로 신뢰성 있게 구분된다 (실측):

| 영상 | 어깨너비 (화면 비율) | 어깨선 y | 골반 가시(vis>0.5) | 발목 가시 |
|---|---|---|---|---|
| best.mp4 (클로즈업 표준) | **0.70** | 0.55 | 0% | 0% |
| carameldansen01 | 0.23 | 0.37 | 100% | 96% |
| carameldansen02 | 0.23 | 0.37 | 100% | 91% |
| carameldansen03 | **0.19** | 0.32 | 100% | 100% |

**분류 규칙**: ① 발목 랜드마크(27/28) 가시성 ≥50% 프레임 → 풀바디/트라이포드,
② 어깨너비 ≥0.45 → 클로즈업(상반신), 0.25 미만 → 풀바디 (그 사이 = 상반신~전신).
두 지표는 실측에서 완전히 일치하며 ①이 더 강건하다 (어깨너비는 팔 동작에 따라 순간 변동).

**분석에 미치는 영향**: 화면 비율 좌표는 프레이밍에 따라 왜곡된다 (같은 "머리 옆 손"이
클로즈업에선 y 0.3, 풀바디에선 y 0.25에 찍히고 x 스프레드도 좁아진다). 그래서 이 문서의
파이프라인은 어깨 중심·어깨너비로 정규화한 body unit을 함께 쓰고, 게임 채보 번역 시에는
프레이밍별 통계를 곡별 choreo 오버라이드(yBase 등)로 환산한다. 게임 자체는 상반신 셀카
프레이밍이므로 풀바디 레퍼런스의 수치를 화면 좌표 그대로 옮기면 안 된다.
