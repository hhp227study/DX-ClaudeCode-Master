# CatchRhy PRD

**Catch the Rhythm.**

## Vision

카메라 기반 AI 리듬게임으로 플레이 자체가 숏폼 콘텐츠가 되는 플랫폼.

## 핵심 기능

-   카메라 플레이
-   손/얼굴/포즈 인식
-   Perfect/Great/Good/Miss 판정
-   AI 자동 채보
-   자동 하이라이트 영상
-   SNS 공유

## 게임 모드

-   Solo(1인플레이)
-   Practice
-   Challenge
-   Daily
-   Endless

## 타겟

15\~30세, K-POP 팬, 리듬게임 유저, 숏폼 사용자.

## MVP

-   로그인
-   음악 선택
-   카메라 실행
-   제스처 판정
-   점수
-   결과 화면
-   영상 저장
-   SNS 공유

## 기술 스택

Frontend: Next.js + TypeScript + PixiJS AI: MediaPipe Tasks Vision,
TensorFlow.js Backend: Spring Boot Infra: Supabase, PostgreSQL, Cloud
Run V2: Unity(Android/iOS/Steam/Desktop)

## USP

-   몸이 컨트롤러
-   숏폼 자동 생성
-   AI 자동 채보
-   UGC 중심 플랫폼
