03 · OPERATING CHARACTERISTICS SHEET 3 / 4

사용자 상호작용과 안정적인 기능 구현에 강점이 있습니다

앱 개발, 디바이스 내장 앱, 공공 웹 시스템, QA 자동화 경험을 연결해 제품을 검증 가능한 상태로 만드는 방식으로 일합니다.

Java와 Kotlin 기반 Android 개발을 중심으로, 실제 사용자가 터치하고 확인하는 화면과 기능 흐름을 구현해 왔습니다. CameraX, Jetpack, OpenCV, ONNXRuntime처럼 제품 요구사항에 맞는 기술을 도입하고 기존 기능을 개선하는 데 익숙합니다.

Gerrit 코드리뷰, JIRA, GitLab, Confluence, Trello로 업무를 추적하고, QA 경험을 바탕으로 기능의 동작 조건과 사용자 관점의 오류 가능성을 함께 확인합니다.

PARAM 01 · BUILD

Android 실무 구현력

무전 앱, 전자칠판, 디바이스 내장 앱에서 UI·상호작용·유지보수를 담당했습니다.

PARAM 02 · VERIFY

제품 품질 관점

네이버 밴드 QA와 Selenium 자동화 경험으로 기능 검증과 개발 커뮤니케이션을 이해합니다.

PARAM 03 · ADOPT

기술 도입과 문제 해결

OpenCV, ONNXRuntime, CameraX, GIS 서버 연동처럼 요구사항에 맞는 기술을 흐름에 연결합니다.

PARAM 04 · SHIP

협업 기반 실행

JIRA, Gerrit, GitLab, Confluence, Trello로 업무 흐름과 개발 문서를 관리했습니다.
