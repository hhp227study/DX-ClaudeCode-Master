# 자기소개 홈페이지 PRD

## 1. 프로젝트 개요

채용담당자가 지원자의 자기소개와 포트폴리오를 빠르게 검토하고, 채용 적합성을 판단할 수 있도록 돕는 개인 홈페이지를 제작한다.

홈페이지는 지원자의 핵심 역량, 프로젝트 경험, 자기소개, 연락처를 명확하게 제공해야 하며, 전문적이고 세련된 인상을 주는 포트폴리오형 웹사이트로 구성한다.

## 2. 핵심 목표

- 채용담당자가 지원자의 역량과 경험을 짧은 시간 안에 파악할 수 있게 한다.
- 포트폴리오 프로젝트를 통해 실무 능력과 문제 해결 능력을 보여준다.
- 자기소개를 통해 지원자의 성향, 강점, 일하는 방식을 전달한다.
- 연락처 정보를 명확하게 제공해 후속 연락으로 이어지게 한다.
- 부드러운 스크롤과 마우스 파티클 효과를 통해 기억에 남는 인터랙션을 제공한다.

## 3. 타겟 사용자

### 주요 사용자

- 채용담당자

### 사용자 특성

- 여러 지원자의 포트폴리오를 빠르게 비교한다.
- 핵심 정보에 빠르게 접근하길 원한다.
- 프로젝트 결과물, 기술 역량, 커뮤니케이션 가능 여부를 중요하게 본다.
- 불필요하게 복잡한 탐색보다 명확한 정보 구조를 선호한다.

## 4. 사용 목적

채용담당자가 지원자의 자기소개와 포트폴리오를 확인하고, 채용 여부를 검증하기 위한 목적으로 사용한다.

## 5. 사이트 구조

홈페이지는 단일 페이지 또는 다중 페이지 구조 모두 가능하나, MVP에서는 단일 페이지 기반 섹션 이동 구조를 우선한다.

### 메뉴 목록

- 홈
- 포트폴리오
- 자기소개
- 연락처

### 권장 URL 또는 앵커 구조

- 홈: `/` 또는 `#home`
- 포트폴리오: `#portfolio`
- 자기소개: `#about`
- 연락처: `#contact`

## 6. 화면 구성 및 섹션 요구사항

### 6.1 홈 섹션

홈 섹션은 사용자가 처음 접하는 첫 화면으로, 지원자의 정체성과 핵심 가치를 즉시 전달해야 한다.

필수 요소:

- 이름 또는 닉네임
- 직무 또는 포지션명
- 한 줄 소개 문구
- 포트폴리오 섹션으로 이동하는 CTA 버튼
- 연락처 섹션으로 이동하는 CTA 버튼

요구사항:

- 첫 화면에서 지원자가 어떤 사람인지 즉시 이해할 수 있어야 한다.
- CTA 버튼 클릭 시 해당 섹션으로 부드럽게 스크롤 이동해야 한다.
- 과도한 장식보다 텍스트 가독성과 첫인상을 우선한다.

### 6.2 포트폴리오 섹션

포트폴리오 섹션은 채용담당자가 지원자의 실무 역량을 판단하는 핵심 영역이다.

필수 요소:

- 프로젝트 목록
- 프로젝트명
- 프로젝트 요약 설명
- 담당 역할
- 사용 기술
- 주요 기능 또는 성과
- GitHub 링크
- 배포 링크 또는 데모 링크

요구사항:

- 각 프로젝트는 카드 형태로 표시한다.
- 프로젝트 카드는 제목, 설명, 기술 스택, 링크 정보를 명확히 포함한다.
- 프로젝트가 여러 개인 경우 그리드 형태로 배치한다.
- 모바일 화면에서는 한 줄에 하나의 프로젝트 카드가 표시되도록 한다.
- 채용담당자가 가장 중요한 프로젝트를 먼저 볼 수 있도록 우선순위를 반영한다.

### 6.3 자기소개 섹션

자기소개 섹션은 지원자의 성향, 강점, 일하는 방식, 성장 방향을 전달한다.

필수 요소:

- 간단한 자기소개 문단
- 핵심 강점
- 업무 또는 학습 태도
- 관심 분야
- 앞으로의 목표

요구사항:

- 장황한 이력서식 문장보다 읽기 쉬운 문단과 짧은 리스트를 사용한다.
- 채용담당자가 지원자의 협업 방식과 성장 가능성을 이해할 수 있어야 한다.
- 추상적인 표현만 사용하지 않고, 경험이나 프로젝트와 연결된 근거를 포함한다.

### 6.4 연락처 섹션

연락처 섹션은 채용담당자가 지원자에게 쉽게 연락할 수 있게 구성한다.

필수 요소:

- 이메일
- GitHub 링크
- LinkedIn 또는 기타 프로필 링크
- 연락 유도 문구

요구사항:

- 이메일 클릭 시 메일 앱이 열리도록 `mailto:` 링크를 사용한다.
- 외부 링크는 새 탭에서 열리도록 한다.
- 연락처 정보는 화면 하단에서도 쉽게 찾을 수 있어야 한다.

## 7. 기능 요구사항

### 7.1 메뉴 내비게이션

- 상단에 메뉴를 표시한다.
- 메뉴 항목은 홈, 포트폴리오, 자기소개, 연락처로 구성한다.
- 메뉴 클릭 시 해당 섹션으로 부드럽게 이동한다.
- 현재 보고 있는 섹션에 해당하는 메뉴 항목은 시각적으로 강조한다.
- 모바일 화면에서는 메뉴가 접히거나 간결한 형태로 표시되어야 한다.

### 7.2 부드러운 스크롤

- 메뉴 클릭, CTA 버튼 클릭, 앵커 이동 시 부드러운 스크롤을 적용한다.
- 스크롤 이동 중 화면 전환이 끊겨 보이지 않아야 한다.
- 브라우저 기본 동작과 충돌하지 않아야 한다.

### 7.3 마우스 잔상/파티클 효과

- 사용자의 마우스 움직임을 따라 잔상 또는 파티클 효과가 표시된다.
- 파티클은 콘텐츠 가독성을 방해하지 않아야 한다.
- 버튼, 링크, 카드 등 주요 UI 요소 클릭을 방해하지 않아야 한다.
- 모바일 또는 터치 환경에서는 효과를 비활성화하거나 성능 부담이 적은 방식으로 대체한다.
- 사용자가 `prefers-reduced-motion` 설정을 켠 경우 애니메이션 효과를 최소화하거나 비활성화한다.

## 8. 디자인 요구사항

- 전체 분위기는 깔끔하고 전문적인 포트폴리오형 디자인으로 한다.
- 채용담당자가 정보를 빠르게 스캔할 수 있도록 명확한 타이포그래피와 섹션 구분을 사용한다.
- 배경, 텍스트, 버튼의 대비를 충분히 확보한다.
- 애니메이션은 보조적인 역할로 사용하고, 핵심 정보 전달을 방해하지 않아야 한다.
- 프로젝트 카드와 CTA 버튼은 일관된 스타일을 사용한다.

## 9. 반응형 요구사항

- 데스크톱, 태블릿, 모바일 화면에서 모두 정상적으로 표시되어야 한다.
- 모바일 화면에서는 메뉴, 프로젝트 카드, 자기소개 텍스트가 좁은 화면에 맞게 재배치되어야 한다.
- 텍스트가 버튼이나 카드 밖으로 넘치지 않아야 한다.
- 가로 스크롤이 발생하지 않아야 한다.

## 10. 접근성 요구사항

- 모든 링크와 버튼은 키보드로 접근 가능해야 한다.
- 포커스 상태가 시각적으로 표시되어야 한다.
- 텍스트와 배경의 색상 대비는 충분해야 한다.
- 이미지가 사용될 경우 적절한 대체 텍스트를 제공한다.
- 애니메이션은 사용자의 모션 감소 설정을 존중해야 한다.

## 11. 성능 요구사항

- 첫 화면은 빠르게 로드되어야 한다.
- 마우스 파티클 효과는 프레임 저하를 유발하지 않아야 한다.
- 불필요하게 큰 이미지나 무거운 라이브러리 사용을 피한다.
- Lighthouse 기준 성능 점수 90점 이상을 목표로 한다.

## 12. SEO 요구사항

- 페이지 제목에는 이름과 직무를 포함한다.
- 메타 설명에는 자기소개와 포트폴리오 목적을 요약한다.
- 주요 섹션 제목은 의미 있는 헤딩 구조를 사용한다.
- Open Graph 메타 태그를 설정해 링크 공유 시 적절한 제목과 설명이 표시되도록 한다.

## 13. 콘텐츠 요구사항

개발 전 준비해야 할 콘텐츠:

- 이름
- 희망 직무 또는 현재 직무
- 한 줄 소개
- 자기소개 본문
- 핵심 강점 3개 이상
- 프로젝트 정보 2개 이상
- 각 프로젝트의 GitHub 링크
- 각 프로젝트의 배포 또는 데모 링크
- 이메일 주소
- GitHub 프로필 주소
- LinkedIn 또는 기타 프로필 주소

## 14. MVP 범위

MVP에서는 다음 항목을 우선 구현한다.

- 홈 섹션
- 포트폴리오 섹션
- 자기소개 섹션
- 연락처 섹션
- 상단 메뉴
- 메뉴 클릭 시 부드러운 스크롤
- 마우스 잔상/파티클 효과
- 반응형 레이아웃
- 기본 SEO 메타 정보

## 15. 추후 확장 기능

- 다크 모드
- 프로젝트 상세 페이지
- 이력서 PDF 다운로드
- 블로그 또는 글 목록
- 다국어 지원
- 방문자 분석 도구 연동
- 문의 폼

## 16. 개발 우선순위

1. 기본 페이지 구조와 섹션 구성
2. 홈, 포트폴리오, 자기소개, 연락처 콘텐츠 배치
3. 메뉴 내비게이션과 부드러운 스크롤
4. 반응형 레이아웃
5. 마우스 잔상/파티클 효과
6. 접근성 및 성능 최적화
7. SEO 메타 정보 설정

## 17. 완료 기준

- 채용담당자가 홈, 포트폴리오, 자기소개, 연락처 정보를 명확하게 확인할 수 있다.
- 메뉴 클릭 시 각 섹션으로 부드럽게 이동한다.
- 마우스 이동 시 잔상 또는 파티클 효과가 자연스럽게 표시된다.
- 모바일과 데스크톱에서 레이아웃이 깨지지 않는다.
- 버튼과 링크가 정상 동작한다.
- 연락처를 통해 이메일 또는 외부 프로필로 이동할 수 있다.
- 애니메이션이 콘텐츠 가독성과 클릭 동작을 방해하지 않는다.
- 기본 SEO 메타 정보가 설정되어 있다.
