About

문제를 구조화하고 끝까지 구현합니다

채용담당자가 확인해야 할 역량을 중심으로, 일하는 방식과 성장 방향을 간결하게 정리했습니다.

저는 사용자가 실제로 마주하는 화면의 완성도를 중요하게 생각합니다. 요구사항을 화면 구조로 바꾸고, 컴포넌트와 상태 흐름을 정리해 유지보수 가능한 방식으로 구현합니다.

프로젝트를 진행할 때는 먼저 사용 목적과 검증 기준을 분명히 한 뒤, 빠르게 동작하는 결과물을 만들고 개선점을 반복해서 반영합니다.

명확한 UI 구조

사용자가 빠르게 이해할 수 있는 정보 배치와 일관된 컴포넌트 설계를 지향합니다.

실행 중심 개발

아이디어를 실제 동작하는 화면으로 빠르게 옮기고, 결과 기준으로 개선합니다.

디테일한 인터랙션

스크롤, 포커스, 호버 상태처럼 경험을 완성하는 작은 움직임을 세심하게 다룹니다.
