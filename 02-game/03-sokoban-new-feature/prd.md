# 소코반 게임 PRD

## 1. 제품 개요

소코반 게임은 단순한 논리 퍼즐을 좋아하는 사용자가 짧은 시간 동안 즐길 수 있는 모바일 중심 퍼즐 게임이다. 사용자는 동굴 배경의 스테이지에서 캐릭터를 움직여 상자를 목표 지점까지 밀어 넣으며 퍼즐을 해결한다.

## 2. 대상 사용자

- 단순한 논리 퍼즐을 좋아하는 사용자
- 버스나 지하철 이동 중 짧게 플레이할 게임을 원하는 사용자
- 복잡한 조작보다 직관적인 퍼즐 풀이를 선호하는 사용자

## 3. 사용 목적

- 대중교통 이동 중 심심할 때 짧게 플레이
- 부담 없이 머리를 쓰는 간단한 퍼즐 경험 제공
- 단계별 난이도 상승을 통해 가벼운 성취감 제공

## 4. 핵심 기능

### 4.1 스테이지

- 총 10개 단계 제공
- 단계는 1단계부터 10단계까지 순차적으로 구성
- 초반 단계는 규칙 학습 중심으로 쉽게 구성
- 후반 단계는 상자 배치와 이동 경로를 더 깊게 고민하도록 구성

### 4.2 게임 배경

- 전체 게임의 시각적 테마는 동굴로 설정
- 바닥, 벽, 목표 지점, 상자, 캐릭터는 동굴 분위기에 어울리는 스타일로 표현
- 어두운 분위기이지만 퍼즐 요소는 명확히 구분되어야 함

### 4.3 이동 및 조작

- 사용자는 캐릭터를 상하좌우로 이동할 수 있음
- 캐릭터가 상자를 밀 수 있음
- 상자는 한 번에 한 칸씩 밀림
- 벽이나 장애물이 있는 방향으로는 이동할 수 없음
- 상자가 벽이나 다른 상자에 막힌 경우 밀 수 없음

### 4.4 애니메이션

- 캐릭터가 움직일 때 부드러운 이동 애니메이션 제공
- 상자를 밀 때도 부드러운 이동 애니메이션 제공
- 애니메이션은 빠르고 명확해야 하며, 퍼즐 플레이 흐름을 방해하지 않아야 함

## 5. 게임 흐름

1. 사용자가 게임을 시작한다.
2. 1단계 스테이지가 표시된다.
3. 사용자가 캐릭터를 이동해 상자를 목표 지점으로 민다.
4. 모든 상자가 목표 지점에 도착하면 단계가 완료된다.
5. 다음 단계로 이동한다.
6. 10단계까지 완료하면 게임 완료 화면을 표시한다.

## 6. 성공 조건

- 각 단계의 모든 상자가 목표 지점에 위치하면 해당 단계 완료
- 10단계까지 모두 완료하면 전체 게임 완료

## 7. MVP 범위

- 1~10단계 소코반 퍼즐
- 동굴 테마 그래픽
- 상하좌우 이동
- 상자 밀기
- 단계 완료 판정
- 다음 단계 진행
- 캐릭터와 상자의 부드러운 이동 애니메이션

## 8. 제외 범위

- 온라인 랭킹
- 사용자 계정
- 스테이지 에디터
- 멀티플레이
- 과금 요소
- 복잡한 스토리 모드

## 9. 비기능 요구사항

- 모바일 환경에서 짧은 시간 안에 바로 플레이 가능해야 함
- 조작 반응이 즉각적이어야 함
- 한 단계는 대중교통에서 짧게 즐길 수 있도록 과도하게 길지 않아야 함
- 퍼즐 요소는 작은 화면에서도 명확하게 식별 가능해야 함
