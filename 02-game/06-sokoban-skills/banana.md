# Codex Rule

이 파일은 저장소 작업 시 Codex가 참고할 수 있는 보조 규칙 문서입니다.

## 적용 원칙

- 기본 저장소 지침은 `AGENTS.md`를 우선합니다.
- 코드 변경 전에는 현재 파일 구조와 기존 스타일을 확인합니다.
- 생성 파일과 수정 파일은 이 프로젝트의 Vite + React 구조에 맞춥니다.
- 수동으로 `dist/` 빌드 결과물을 편집하지 않습니다.
- 변경 후에는 가능한 경우 `npm run build`로 검증합니다.

## 응답 방식

- 설명은 짧고 구체적으로 작성합니다.
- 실행한 명령과 검증 결과를 명확히 공유합니다.
- 테스트나 빌드를 실행하지 못한 경우 그 이유를 함께 남깁니다.
